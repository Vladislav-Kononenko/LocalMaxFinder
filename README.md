Local Max Finder

Программа для поиска локальных максимумов в многомерных массивах. Она фиксирует заданную ось и в каждом срезе находит элементы, которые строго больше всех своих соседей по остальным измерениям. Приложение имеет графический интерфейс, поддерживает пакетную обработку файлов и сохраняет результаты в текстовые файлы.
